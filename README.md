# Веб-приложение с рассылкой сообщений

1. Описание:
```
 Веб-приложение которое позволяет пользователям управлять рассылками сообщений для клиентов.
 Приложение включает функциональность для создания, просмотра, редактирования и удаления рассылок, а также отправки сообщений по требованию.
```
2. Клонируйте репозиторий:
```
    1) HTTPS 
            https://github.com/DGBIZT/Coursework_4_Mailing_management_Service.git
    2) SHH
            git@github.com:DGBIZT/Coursework_4_Mailing_management_Service.git
```
###### №1 Разработка сервиса
```
1. Управление клиентами
2. Управление сообщениями
3. Управление рассылками
    Статусы рассылки:
        Создана — рассылка была создана, но еще ни разу не была отправлена.
        Запущена — рассылка активна и была отправлена хотя бы один раз.
        Завершена — время окончания отправки рассылки прошло.
4. Отправка сообщений по требованию
5. Попытки рассылок
    Попытка рассылки — это запись о каждой попытке отправки сообщения по рассылке. 
    Она содержит информацию о том, была ли попытка успешной, когда она произошла и какой ответ вернул почтовый сервер.
6. Главная страница
    На главной странице отображается количество всех рассылок, количество активных рассылок (со статусом 'Запущена') и количество уникальных получателей.
```
###### №2 Расширение функциональности
```
7. Регистрация и аутентификация пользователей
    * Реализована система регистрации и аутентификации пользователей.
    * Пользователи имеют возможность зарегистрироваться на сайте, подтвердив свой email
    * Реализована функция входа и выхода из системы.
    * Реализована возможность восстановления пароля.

8. Статистика и отчеты
    * Собирается и отображается информации о количестве успешных/неуспешных попыток рассылок пользователя и количестве отправленных сообщений.
9. Ограничение доступа
    Описание ролей и прав доступа:
        1) Пользователь
                * Создание, просмотр, редактирование и удаление своих клиентов и рассылок.
                * Просмотр статистики по своим рассылкам.
        2) Менеджер
                * Просмотр всех клиентов и рассылок.
                * Просмотр списка пользователей сервиса.
                * Блокировка пользователей сервиса.
                * Отключение рассылок.
10. Кеширование
    * Настроено серверное и клиентское кеширование для повышения производительности.
```
###### №3 Практическая часть
```
    1) Создайте БД в PostgreSQL (CREATE -> DATABASE -> SAVE)
    2) В pycharm клонируете репозиторий указанный выше.
    3) Переименнуйте файл .env.exemple в .env и внесите свои данные.
    4) Введите команду python manage.py migrate.
        Благодаря этой команде вы сконектитесь с вашей БД.
    5) Обязательно обновите все зависимости: введите команду poetry update
    
    6) Далее поочередно, соблюдайте последовательность!!!
        Команды:
            
            * python manage.py createadmin 
                - Создастся пользователь-администратор с входными данными email = 'testadmin@sky.pro' и password '1234'
            
            * python manage.py create_group_m.py
                - Создается группа Менеджер с правами доступа:
                    * Просмотр всех клиентов и рассылок.
                    * Просмотр списка пользователей сервиса.
                    * Блокировка пользователей сервиса.
                    * Отключение рассылок.
           
            * python manage.py create_group_users 
                - Создается группа Пользователи с правами доступа:
                    * Создание, просмотр, редактирование и удаление своих клиентов и рассылок.
                    * Просмотр статистики по своим рассылкам.
            * python manage.py create_permissions
                - Создается разрешение на блокоровку пользователей
      
      Далее будут описаны несколь команд по заполнению клиентов, и сообщений только для демонстративной части, 
      вся информация придумана и не имеет отношение к реальным данным. Реальные данные занесете самомтоятельно на странице Веб-приложения.
      Если имеете опыт, то можете в каcтомной команде add_recipients.py указать своих получателей и в add_messages.py указать свои темы и тексты сообщений,
      все они будут привязаны к пользователю admin.
            * python manage.py add_recipients
                - заполняется список получателей
            
            * python manage.py add_messages
                - Заполняется список сообщений состоящий из тем и текста
      
      Так же реализована отправка рассылки через командную строку (кастомной командой).
            *   python manage.py send_newsletter 
                - Правильный синтаксис запуска команды:
                    * python manage.py send_newsletter --subject="Новость дня" --message="прекрасная погода" --recipients="1,2"
                    Где:
                        --subject="Новость дня"         - тема письма
                        --message="прекрасная погода"   - текст сообщения
                        --recipients="1,2"              - список ID получателей через запятую
      
    7)  Установите Redis Server (Remote Dictionary Server) — это высокопроизводительная система управления базами данных (СУБД) с открытым исходным кодом, которая хранит данные в оперативной памяти в формате ключ-значение.  
        Запустите  redis-server.exe и не закрывайте покане прекратите работать с приложением
        В командной строке введите команду redis-cli далее select 1 -  выбираем базу данных внутри Redis.  
                       
```
